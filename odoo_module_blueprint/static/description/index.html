How to use

Setup in a few clear steps

Connect Google, create a mapping, choose fields, and click Sync Now.

1

Create a Google Cloud service account

Enable Google Sheets API and Google Drive API in Google Cloud. Create a service account and download the JSON key.

2

Share the Google Sheet with the service account

Open your Google Sheet and share it with the service account email as Editor. Paste only the email address, not the full JSON line.

3

Create the connection in Odoo

Go to Google Sheets → Connections, create a new connection, and paste the full service account JSON.

4

Create a mapping

Go to Google Sheets → Mappings, choose the Odoo model, paste the Spreadsheet ID, enter the Sheet tab name, and add field mappings.

5

Click Sync Now

The connector sends the selected Odoo records to Google Sheets and records the result.

Important setup notes

Most setup errors are easy to fix

If sync does not send data, check these items first. They solve most Google Sheets connection issues.

  • ✓The Google Sheet must be shared with the service account email as Editor.
  • ✓The Spreadsheet ID must be only the ID from the URL, not the full URL.
  • ✓The Sheet Name must exactly match the tab name at the bottom of Google Sheets.
  • ✓The Google Sheets API must be enabled in Google Cloud.
  • ✓The service account JSON must be pasted fully, including private key content.
